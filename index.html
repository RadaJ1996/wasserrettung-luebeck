Discord-Integration

Diese HTML-Demo kann Discord nicht sicher direkt anbinden. Für die echte Version wird ein kleiner Server/Bot benötigt. Die Oberfläche ist bereits vorbereitet.

So funktioniert es später

1. Dienst wird auf der Website erstellt Website
2. Bot postet ihn automatisch in Discord Discord
3. Mitglied klickt „Zum Dienst“ Button
4. Website prüft Qualifikationen / Verfügbarkeit Prüfung
5. Anmeldung landet im Dienstplan Gespeichert
